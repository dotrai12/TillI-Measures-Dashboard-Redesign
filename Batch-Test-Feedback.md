- **F1** (Tilli → All Schools, list view, desktop) — On Mango Tree's row, the pink "needs you" dot and an **ⓘ** icon sit **on top of the start of the school name** ("Mango Tree School"), overlapping the "M" and the line under it ("Independent school · MANG-7595"). They should sit beside the name, not over it. ✅
- **F2** (Tilli → a school's hub, the tab row Overview · Students · Staff & Access · …, desktop) — A **scroll bar shows at the right end of the tab row**. Likely cause: the row is set to scroll sideways on narrow screens (`.ui-tabs.hub { overflow-x: auto }`), which makes the browser treat it as a scroll box both ways; the active tab's green underline sits 1 px below the row's edge, so it "overflows" downwards and a vertical scroll bar appears. Fix: hide the vertical overflow / hide the scroll bar on that row. **Also on phones** (seen 30 Oct): the row scrolling sideways is fine — keep it — but there must be **no vertical scroll bar**. ✅
- **F3** (Tilli → a school → Assessments → Plan & deploy → **Academic year** card) — The year strip ("**2026–27 · current**" pill row) should only show for a school in its **second year with Tilli or later**. In a school's first year (only one year on record) hide it — there's nothing to switch between. The card itself (dates, Plan from calendar, Edit dates, Start new year) stays. ✅
- **F4** (Tilli → a school → Assessments → Plan & deploy → **Parents take part** switch) — Move the switch **below the Baseline / Midline / Endline tabs**, instead of above them between "Deployments" and the tabs. Placement only — it stays one setting for the whole school (it decides whether My School Check-in runs at home or at school). ✅
- **F5** (same **Parents take part** switch, while a phase is live) — Remove the orange line "Locked while Midline is live — changing it asks whether to apply it now or from the next phase." Instead, show the switch **disabled with a small lock** while a phase is live; the explanation appears on **hover** (desktop) or **tap** (phone). ✅
- **F6** (Tilli → a school → Assessments → Plan & deploy → a phase's **End now** / **Undeploy**) — **Undeploy** deletes the phase as if it was never sent: teachers, parents and children stop seeing it, and anything already done stops showing or counting (no results, no Missed). **End now** closes the window today and keeps everything (done counts, not done = Missed, results produced). Having Undeploy beside End now on a live phase with data is risky. Fix: offer **Undeploy** only while a phase is **Scheduled** or nothing has been recorded yet; once anything is done, hide it (or show it disabled with a hover/tap reason) and leave **End now**. ✅
- **F7** (Add School wizard → Grades step, and Grades & sections → **Quick add** → the custom row "Base grade… · School's name for it · Add") — The two boxes aren't explained, "Base grade…" looks like a text box though it's a dropdown, and the second hint is cut off. Make the row read as one sentence: **"Add [Grade 1 ▾] called [Sunflowers] (optional) → Add"**, with a hint under it: "Only if the school uses its own name for a grade." The base grade is still what Tilli uses for promotion and matching; the name is what screens show ("Sunflowers (Grade 1)"). ✅

  - **Quick add** fits in 2 rows at the wider size; grades already added stay, greyed, so nothing jumps. Custom row = F7.
